# 增量技术设计：视觉体验 2.0（对应 PRD docs/prd/2026-11-03-visual-2.0.md）

已拍板：动效默认「标准」+ 引导时可选；8 套新主题一次做完；渐变强调色默认开。纯前端，不动 Rust 侧，不引新运行时依赖。

## 1. 方案概览（P0 逐项）

- **P0-1 动效系统**：`store.ts` 新增偏好 `motion/motionExplicit`，`apply.ts` 把生效档位写 `data-motion` 到 `<html>`；`global.css` 所有动画（含新增 shimmer、hover 抬升、View Transitions）只走 transform/opacity，文件末尾一个 `[data-motion="off"]` 块统一断闸；`ui.tsx` 的 `useCountUp` 按档位调 duration（off=0）。这样动效开关是单一 DOM 属性，组件零条件渲染，最稳。
- **P0-2 卡片深度**：`tokens.ts` 的 `cardShadow()` 改由 `elevation(0-3)` 求解（0=none，暗色档配低透明大阴影+`--hairline-strong` 描边补偿），移除「material=flat 一律 none」的旧规则；`--shadow-card` 继续走既有 applyTheme 内联变量通道，CSS 侧 `.t-card` 只加 hover 抬升（translateY -2px + shadow 过渡）。无架构改动。
- **P0-3 渐变强调色**：`ThemeInput` 新增 `accent2?` 与 `gradientAccent?`（默认 true）；`accent2` 缺省由 accent 色相 +36° 派生（复用 hsl 工具），并过 `ensureTextContrast` 同一门槛；`themeVars` 新增 `--color-accent2` 与 `--gradient-accent`（关档时直接回退为 accent 纯色，消费方无感知）；`Btn` primary、`.nav-item` 选中线、StatCard 数字改消费该变量。
- **P0-4 主题 8→16**：纯数据新增到 `presets.ts` 的 `BUILTIN_THEMES`（4 暗 4 亮），全部过 `buildTheme` AA 求解；`parseTheme` 补新字段校验（clamp glow 0-100、elevation 0-3、hex 校验 accent2），旧导入 JSON 缺字段自动落默认值，零迁移成本。
- **P0-5 统计卡重做**：`ui.tsx` 的 `StatCard` 加图标 accent-soft 圆角底座、数字渐变（`--gradient-accent` + 既有 `.num` tabular-nums）、复用 `card-hover` 反馈；对外 props 不变，CostDashboard 等调用点零改动。
- **P0-6 氛围强度**：glow 从「material 专属」改为主题参数 `glow 0-100`；`themeVars` 写 `--glow = glow/100`，`global.css` 的 `body::before` 改 `opacity: var(--glow)`，颜色仍取主题 accent。glass 主题默认 55，其余默认 0，内置主题逐套指定。
- **P0-7 首启引导**：新组件 `OnboardingOverlay.tsx`（Modal 同款焦点圈定），3 步：功能一览→主题选择（预览色卡，可直接切换）→动效档位选择；完成或跳过都置 `onboardingDone=true`（persist 持久化，永不复弹）；`App.tsx` 挂载。尊重 data-motion（off 档用淡入替代位移动画）。

## 2. 数据结构

```ts
// tokens.ts —— ThemeInput 新增（全部可选，缺省由 buildTheme 派生，旧数据零破坏）
accent2?: string;          // 渐变第二色；缺省 = accent 色相+36°，过 ensureTextContrast(4.6)
gradientAccent?: boolean;  // 默认 true（总监拍板）；false 时 --gradient-accent=accent 纯色
glow?: number;             // 0-100；默认 material==="glass" ? 55 : 0
elevation?: 0|1|2|3;       // 默认 material==="flat" ? 1 : 2；0=无阴影（terminal/ink/void 设 0）
// ThemeTokens.vars 新增：--color-accent2、--gradient-accent、--glow(0-1 字符串)；
// --shadow-card 改由 elevation 求解。chart 不加字段（图表不需要渐变）。

// store.ts —— UiState 新增（persist version 3→4，migrate 补默认值）
motion: "off" | "standard" | "rich";  // 默认 "standard"
motionExplicit: boolean;              // 用户显式选过档位=false→系统 reduced-motion 时生效档降为 off
onboardingDone: boolean;              // 默认 false
// 生效档位 = motionExplicit ? motion : (matchMedia("(prefers-reduced-motion: reduce)") ? "off" : motion)
// migrate(persisted) 追加：motion:"standard", motionExplicit:false, onboardingDone:false（参考现有写法）
// partialize 追加这三个字段。

// HTML data 属性约定（apply.ts 写入）
data-motion="off"|"standard"|"rich"   // CSS 唯一动效开关；组件不感知档位
// elevation/gradient 不需要 data 属性：走 --shadow-card / --gradient-accent 变量即可
```

## 3. CSS 策略

- **硬规则**：所有 keyframes/transition 只动 `transform` 与 `opacity`；阴影/发光变化走 shadow token 预先声明 + opacity 复合层，禁止 width/left/color 动画。
- **keyframes 清单**（放 `global.css` 既有 keyframes 区，与 `.animate-in` 同层，不进 `@layer`——现状动效类都在层外，保持一致）：`rise-in`/`fade-in`（已有）、新增 `shimmer`（骨架屏，translateX 位移的渐变条）、`vt-in`/`vt-out`（View Transitions 的 `::view-transition-old/new` 专用）。transition 清单：`.card-hover` 追加 `transform .15s ease, box-shadow .15s ease`（hover 抬升）；`.t-btn` 追加 `transform .12s`（active 微缩）。
- **View Transitions**：视图切换用 `document.startViewTransition` 包裹（标准/满格档才调用）；CSS 侧 `@supports (view-transition-name: root)` 守卫定义 old/new 动画，不支持的 WebView 直接瞬时切换，无降级成本。
- **关档集中断闸**：文件末尾统一块 `[data-motion="off"] .animate-in, …, [data-motion="off"]::view-transition-group(*)` 全部 `animation: none; transition-duration: 0s`，替代散落各处的媒体查询；`prefers-reduced-motion` 不再直接断闸 CSS，改由 store 生效档位逻辑处理（保住「允许覆盖」语义）。

## 6. 共享约定

1. 新增 CSS 变量必须同时进 `tokens.ts` 的 `themeVars`；`@theme` 首帧兜底仅补 `--gradient-accent`/`--glow`（只影响首帧背景，不加新颜色值）。
2. 新主题/新用色必须过 `buildTheme` 的 AA 求解，禁止手调 rgba 绕过；`accent2` 与 accent 同门槛（4.6）。
3. 动效只允许 transform/opacity；新增动画必须能被 `[data-motion="off"]` 断闸，且不新增 `prefers-reduced-motion` 散落块。
4. 组件不读 store 的 motion 字段，只依赖 data-motion 或 CSS；`useCountUp` 是唯一 JS 动效例外。
5. e2e 视觉基线重生成只允许在 T05（QA 阶段）做一次，中途禁止随改随更。
6. persist 迁移只补齐不覆盖：新偏好字段一律给默认值，不得读旧值抛错。
7. `parseTheme` 对外部 JSON fail-closed 原则不变：新字段只 clamp/落默认，不因缺失拒绝。

## 7. 风险与回退

1. **View Transitions 兼容**：WebView2 支持但旧 runtime 可能没有 API → JS 侧 `typeof document.startViewTransition === "function"` 守卫，回退瞬时切换。
2. **渐变数字可读性**：accent→accent2 渐变在浅色主题上可能局部掉对比 → accent2 已过 AA，且渐变两端均为安全色；风险残留时按主题关闭 gradientAccent（token 级回退）。
3. **glow 大图层性能**：`body::before` 是 fixed 全屏层 → glow 值只改 opacity 不改层数，0 值主题可加 `visibility` 短路；实测掉帧则内置主题降 glow 档。
4. **persist v4 迁移丢偏好**：migrate 只增字段不删旧值，`partialize` 白名单遗漏只会导致字段不持久化（回默认值），无崩溃路径；store.preferences.test.ts 锁行为。
5. **8 主题一次做 AA 不达标**：buildTheme 会自动提亮/压暗 accent 到 4.6，最坏情况是色相略偏；极端无解时该主题 accent 就近取对比度最高档（现有 highestContrast 兜底），不阻塞交付。
